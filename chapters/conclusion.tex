\chapter*{Conclusion}
\addcontentsline{toc}{chapter}{Conclusion}

Ce TP a permis de mettre en pratique les notions essentielles du module
«~\moduleNom~»~: manipulation des structures de données, écriture et
exécution de programmes, puis analyse des résultats. Les objectifs fixés ont
été atteints et le code produit fonctionne correctement sur les jeux de
tests considérés.

Comme piste d'amélioration, on pourra~:
\begin{itemize}[leftmargin=1.2em,itemsep=1pt]
  \item optimiser l'algorithme de tri (tri rapide, tri fusion) ;
  \item ajouter une validation des entrées utilisateur ;
  \item écrire des tests unitaires pour automatiser la vérification.
\end{itemize}
